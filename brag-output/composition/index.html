21.8 Determinantal Rank of Indefinite Hessian Matrices

Recall Lemma 21.4: Let $M \in \mathcal{M}_{n \times n}(\mathbb{C})$ satisfy $M^* = M$. For any non-degenerate bilinear transformation $T(u, v) = u^T A v$:

$$\det(\lambda I - A) = \sum_{\sigma \in S_n} \text{sgn}(\sigma) \prod_{i=1}^n A_{i, \sigma(i)} \equiv \lambda^n - \text{tr}(A)\lambda^{n-1} + \dots + (-1)^n \det(A) = 0$$

Lemma C.12: Uniform Bound on Stirling Sums

$$\forall \varepsilon > 0, \, \exists N \in \mathbb{N} \text{ s.t. } \forall n > N, \, \left| \sum_{k=1}^n \frac{(-1)^k \binom{n}{k}}{k^2 + 1} - \zeta(2) \right| < \frac{\varepsilon}{\ln(\ln n)}$$
